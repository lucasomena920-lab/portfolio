Como encaro
um projeto

Começo pelo conteúdo e pelo que a pessoa precisa de fazer no site. A partir daí, organizo as páginas, trabalho o layout e acrescento as interações necessárias.

Interessa-me tanto a parte visual como o que acontece por trás: um formulário com validação, uma consulta à base de dados ou um pedido AJAX que atualiza a interface.

Quero que o resultado funcione bem no telemóvel e seja fácil de alterar mais tarde. Prefiro explicar as escolhas no código e nos projetos a preencher o portfólio com promessas.

Base técnica

Com o que trabalho.

01 / Interface

HTML & CSS

Estrutura semântica, organização dos estilos e layouts que se adaptam ao conteúdo e ao ecrã.

02 / Interação

JavaScript & AJAX

Eventos, validação de formulários e pedidos assíncronos para atualizar dados sem recarregar a página.

03 / Conteúdo e dados

WordPress & SQL

Gestão de conteúdo em WordPress e bases de dados relacionais: tabelas, relações e consultas.
